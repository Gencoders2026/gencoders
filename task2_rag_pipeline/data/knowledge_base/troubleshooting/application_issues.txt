APPLICATION ISSUES - TROUBLESHOOTING GUIDE

Application Will Not Open

Problem:
The application fails to start or closes immediately.

Recommended Steps:

Restart the application.
Restart the device.
Check the internet connection if the application requires online access.
Make sure the application is updated.
Check whether the device meets the application's system requirements.
Reinstall the application if necessary.
Application Is Running Slowly

Problem:
The application is slow, freezes, or takes a long time to respond.

Recommended Steps:

Close unnecessary applications.
Restart the application.
Restart the device.
Check the internet connection.
Make sure sufficient device storage is available.
Update the application to the latest supported version.
Clear application cache if the option is available.
Application Crashes

Problem:
The application unexpectedly closes.

Recommended Steps:

Reopen the application.
Restart the device.
Update the application.
Check available storage.
Clear the application's cache if supported.
Reinstall the application if the issue continues.

If crashes continue, contact support with:

Device type.
Operating system and version.
Application version.
Steps that cause the crash.
Any error message displayed.
Feature Not Working

Problem:
A specific application feature does not work as expected.

Recommended Steps:

Confirm that the feature is available for the customer's account or subscription.
Restart the application.
Check for application updates.
Verify the internet connection.
Try the feature again.
Check whether the issue occurs consistently.

Provide support with the exact steps that reproduce the problem.

Error Message

Problem:
The application displays an error message.

Recommended Steps:

Record the exact error message.
Take a screenshot if appropriate and safe.
Note what action caused the error.
Restart the application.
Try the action again.
Contact support if the error continues.
Data Not Updating

Problem:
Information displayed in the application appears outdated.

Recommended Steps:

Refresh the application.
Check the internet connection.
Sign out and sign back in.
Restart the application.
Allow time for synchronization if the service processes updates asynchronously.
Contact support if the information remains incorrect.
Application Update Problems

Problem:
The customer cannot install the latest application update.

Recommended Steps:

Check available device storage.
Verify the internet connection.
Restart the device.
Try the update again.
Check whether the device supports the new application version.
Reinstall the application if appropriate.
When to Escalate

Escalate the issue to technical support when:

The problem continues after standard troubleshooting.
Multiple users are experiencing the same issue.
The application is completely unavailable.
Customer data appears incorrect or missing.
A security-related problem is suspected.
An error cannot be resolved using the standard troubleshooting steps.

When contacting support, provide:

Account information.
Device and operating system.
Application version.
Exact error message.
Steps to reproduce the issue.
Approximate time the problem occurred.
Screenshots or logs where appropriate and safe.
